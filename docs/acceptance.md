## 运行结果

| 项目 | 方法及观察结果 |
| --- | --- |
| 生成与内部链接 | `python3 tools/archive.py build` 与 `python3 tools/archive.py check --base main` 通过。5 个 HTML 页面合计检查 61 处内部引用，含重复导航、资源、canonical 和片段。手动打开旧首页 `#notes`、安萨里 `#ref4`，均命中预期内容。 |
| HTTP | 从本机预览逐项 GET 5 个 HTML、CSS、JavaScript、SVG、站点地图和 JSON 目录，10 项均为 HTTP 200。 |
| 索引筛选 | 初始 2 条。LN 与 Philosophy 组合得到安萨里 1 条；加入 11 月 17 至 23 日区间得到 0 条和空提示；清空恢复 2 条。首尾同为 11 月 23 日时命中方法札记，倒置日期显示纠错提示。按 Philosophy 筛选后刷新可恢复同一结果。 |
| 手机与桌面 | 用 Chrome 对全部 5 页在 320、390、1280 CSS 像素视口逐页测量，共 15 组，文档宽度均等于视口宽度；另目视检查桌面首页与手机索引。日期输入使用浏览器本地格式。 |
| 可访问性与抓取 | 键盘第一次 Tab 命中跳至正文。筛选有显式 label、原生控件与结果播报。用禁止脚本的本机 HTTP 响应打开研究页，仍有 2 条作品及可访问的普通链接。每页一个 H1，有文档语言、viewport 与唯一锚点。 |
| 版本与关联 | 展开安萨里的引用与版本记录，两个固定提交链接可查。临时样稿的正向和反向演进关系都出现在对应作品页。 |
| 新手札演练 | 在隔离副本起草一篇双语流程试样，补齐两份源文件后生成私人预览，正式工作树与目录无变化。仅在临时副本模拟准入，两份文件便生成文章、首页、索引、JSON 和站点地图。再将其改编为 WP，原 RN 编号与网址保持一致。试样及私人附档均未进入交付树。 |
| 错误路径 | 演练验证了私人状态误入公开目录、未替换写作提示、P 缺发表记录、未发表稿误标已评审、重复 URL、未知关系、损坏锚点、陈旧生成页、删除既有编号、修改永久路径、不升级版本改正文等情况会被拒绝。 |
| 公开范围 | 对照既有公开原文、Profile 和新增文件清单。研究正文仅有两篇；联系入口沿用原站已公开地址。没有将私人原始资料、样稿、投稿材料、内部项目或新研究结论带入网站。 |
