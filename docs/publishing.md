# 从私人研究到公开档案

## 研究资料在哪里

| 层级 | 位置与可见性 | 在何时进入下一层 |
| --- | --- | --- |
| Private Research | 本机私人目录或明确为 private 的仓库。放原始笔记、扫描、观察记录和投稿资料。 | 找到一个有材料支撑、值得解释的问题。 |
| Review Draft | 同样位于公开仓库以外。整理可展示的正文、元数据、引用和私人审批记录。 | 研究者看过具体文本、版本和公开范围，确认哪些字句、材料可以进入公开分支。 |
| Public Archive | 公开仓库上的已授权稿件和静态页面。生产 Pages 从 `main` 根目录发布。 | 研究者确认本次最终页面和发布动作后，才能合并生产分支。 |

公开仓库中的分支、Draft PR、Git 历史和可猜到的网址都可能被他人阅读。私人证据单独保存，后续只复制已确认的公开文件。`noindex` 只用于提示搜索引擎。

## 写一篇候选手札

在网站仓库中运行以下命令。目标目录应为尚不存在的私人目录，位于公开仓库之外。命令会写入 `record.json` 和 `body.html.inc`，默认类型 RN、语言为中文。用 `--lang en` 或 `--lang both` 可以生成英文或双语骨架。

```sh
python3 tools/archive.py draft ../private-research/my-note
```

在 JSON 里写标题、摘要、领域、关键词和本次具体改动。在正文中按问题需要保留标题下的章节，可短至一项考证。核对自己实际读过的版本、页码、原文和反例。研究问题、背景、文献与证据、当前发现、个人判断或假说、局限、参考文献在正文中编写；标题与修订记录由元数据生成。清掉模板提示后生成完整本地预览。

```sh
python3 tools/archive.py preview ../private-research/my-note
```

打开命令输出的 `preview/index.html`，也可打开同目录里的候选文章。审阅预览仅将这篇候选与既有公开条目组合，所有页面带本地审阅提示，日期为拟定值。私人目录里的观察笔记、审阅记录等旁文件不会随模板被复制。

## 证据与投稿审核

- 对每一个结论写下读者能追查的来源和精确位置。明确材料支持的最小判断，交代尚缺的版本、反例或替代读法。尚未得出结论也可以形成有用手札。
- 涉及术数、命理或超自然现象时，逐项区分 **历史文献、传统理论、观察记录、个人解释、待验证假说**。记录时间、文本或说话人所报告的经验，并标明独立核验程度。公开前处理可识别个人的信息和材料使用范围。
- 拟投稿作品先确定实际目标期刊，阅读其官网有关预印本、个人网站、既往公开发表和版权的现行说明。在私人记录中保存政策链接、核对日期、对应版本和判断。政策不明或可能影响投稿时，候选稿留在私人审阅层，待研究者作出选择。
- 企业内部材料、私人通信、未获授权的图片或长段原文不能随公开稿进入分支。真实发表记录是 P 的前提。没有正式发表记录的稿件使用适当的未发表类型。
- 审阅时把 **具体文件、编号、版本、公开范围** 交给研究者确认。确认只覆盖相应的内容和动作；正文或公开范围有实质性改动时，对变更部分重新核对。

## 获准后进入网站分支

核对候选号与当前基线。将候选元数据的 `release` 改为 `public`，落实实际的首发日、版本和修订记录日期。以下为默认 RN 的示例，把 `RN-0001` 替换为已确认编号。在独立分支运行，仅复制这两个文件。

```sh
work_id=RN-0001
draft_dir=../private-research/my-note
mkdir "archive/works/$work_id" &&
  cp "$draft_dir/record.json" "$draft_dir/body.html.inc" "archive/works/$work_id/"
python3 tools/archive.py build
python3 tools/archive.py check --base origin/main
```

逐项审查变更后提交 Draft PR，附本地预览、证据核对摘要、版本变化和未决项。发布前核对待合并提交与已审版本一致。最终确认后按授权合并，复查 Pages 运行结果、作品原路径、索引筛选和引用文本。若一次确认已明确覆盖稿件及生产发布，按其确切范围执行。

## 修订已公开手札

编辑原编号对应的两个源文件。正文有改变时，在历史中给此前版本补上指向当时提交的永久链接，追加本次修改及日期。独立发展出的新成果另编一号，并登记与前作的关系。复查、预览和授权步骤沿用同一流程。
